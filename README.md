# Task Arrange

任务排布与管理扩展 — 在 Project Graph 中将文本节点组织为任务树，通过快捷键快速管理任务状态。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `O K K` | 切换选中节点的 ✅ 完成状态 |
| `E R R` | 切换选中节点的 ❌ 失败状态 |
| `T R R` | 将选中节点所属树的根节点设为 🛠️ 任务树根 |

## 功能

### 任务状态管理
- **OKK**：未完成节点标记为 ✅ 完成（绿色），已完成节点撤销标记
- **ERR**：未失败节点标记为 ❌ 失败（暗红色），失败节点撤销标记

### 任务树与自动高亮
- **TRR** 设置任务树根节点（🛠️）
- 系统自动计算"就绪"任务并标记 📌：
  - 所有子节点顺序链已完成 → 该节点就绪
  - 所有前序节点已完成 → 该节点就绪
- 就绪节点高亮为橙色，含搁置关键词的为黄色

### 日期倒计时
支持多种日期格式，自动计算截止日期并显示倒计时与紫色色阶：

| 格式 | 示例 |
|------|------|
| `YYYY年M月D日` | 2026年5月19日 |
| `YYYY-M-D` | 2026-05-19 |
| `YY-M-D` | 26-05-19 |
| `M月D日` | 5月19日 |
| `M-D` | 05-19 |

截止日越近颜色越深（白 → 浅紫 → 深紫）。

### 搁置管理
节点文本包含"搁置"、"delay"、"@de"时，自动识别为搁置状态，影响高亮颜色和日期语义。

### 智能焦点转移
状态变更后，自动将选择焦点转移到下一个就绪任务，支持多节点批量操作后的合理焦点定位。

## 节点文本前缀约定

```
[✅/❌] [🛠️] [📌] [⏳ n天] 原始内容
```

## 安装

将 `.prg` 文件拖入 Project Graph 即可安装。
